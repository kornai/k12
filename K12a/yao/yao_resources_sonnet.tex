\section{Introduction}
Yao (Chiyao, Ciyawo; ISO 639-3 yao; Bantu) is spoken mainly in Malawi and Mozambique. This report lists only resources that appeared in search results. I did not find a current school primer.

\section{Primary Educational Resources}
\begin{itemize}
\item The search summary mentions Kaunjika, ``A Chiyao course in three languages'' (Montfort Media, Balaka, 2006), a learner course. I did not see a page for it, so there is no link.
\item The search summary mentions historical primers by R. S. Hynde (1892 and 1894). I did not see a page for them either.
\item Peace Corps Malawi language training material, which the search summary says was adapted from the Chichewa version. \url{https://www.langcen.cam.ac.uk/resources/langn/data/ny_106.html}
\end{itemize}

\section{Linguistic and Reference Materials}
\begin{itemize}
\item Ciyawo website with information on the language, including the Ciyawo--English dictionary project led by Ian Dicks. \url{https://ciyawo.org/node/1}
\item Research papers and academia page on the same site. \url{https://ciyawo.org/node/9}
\item Dicks and Dollar, \emph{A Practical Guide to Understanding Ciyawo} (Kachere Series, Malawi). \url{https://africanbookscollective.com/?p=13331}
\item Overview of the Yao language. \url{https://en.wikipedia.com/wiki/Chiyao}
\end{itemize}

\section{Religious and Community Resources}
None found in these searches.

\section{Digital and Audio Resources}
The ciyawo.org site is the main digital hub found. No audio collections were identified.

\section{Curriculum Development Context}
The Malawian orthography is based on Chewa spelling, and orthographies differ across countries. A school curriculum would need to settle this. Learner-oriented grammar and dictionary materials exist, but I found no school textbooks in Chiyao.
