\section{Introduction}
Fam (ISO 639-3 \texttt{fam}, Glottocode famm1241) is an endangered Bantoid language of Taraba State, Nigeria. Search results report very few speakers (fewer than 500 according to Wikipedia; a 1984 figure of about 1,000 is cited in an older version). Speakers call the language Fam or Awol Fam. This search found no educational materials of any kind; only descriptive and demographic pages exist.

\section{Primary Educational Resources}
None found. No primers, textbooks or school programmes for Fam appeared in search results.

\section{Curriculum Development Context}
Fam has very few speakers and, as far as these searches show, no written tradition or teaching materials. Any curriculum would have to begin with documentation (wordlists, recordings, an orthography) in cooperation with the community; the sources above offer only a starting point for that work.
