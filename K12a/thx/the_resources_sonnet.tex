\section{Introduction}
The code thx (Glottolog thee1240) was retired from ISO 639-3 as a duplicate of Oy [oyb] (change request 2014-014, adopted 2015-01-12). Glottolog keeps it only as a bookkeeping entry, located in Laos. It is not a distinct language, so no separate K-12 resources exist under this code.
