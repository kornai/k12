\section{Introduction}
Fore (ISO 639-3 \texttt{for}) is a Trans--New Guinea language spoken in the Okapa district, Eastern Highlands Province, Papua New Guinea. The main documented resources are Graham Scott's grammar and dictionary. No school or literacy materials were found.

\section{Primary Educational Resources}
No primers, textbooks or vernacular school materials were found in search results.

\section{Linguistic and Reference Materials}
\begin{itemize}
\item Scott, \emph{The Fore Language of Papua New Guinea} (ANU PhD thesis, open access; phonology, morphophonemics, syntax): \url{https://openresearch-repository.anu.edu.au/items/45a1eeba-eb8c-4651-9554-c3957a4655ea}
\item Scott 1978, \emph{The Fore Language of Papua New Guinea}, Pacific Linguistics B-47 (Glottolog reference entry): \url{https://glottolog.org/resource/reference/id/107238}
\item Scott 1980, Fore dictionary, Pacific Linguistics C-62, 243 pages (Glottolog reference entry): \url{https://glottolog.org/resource/reference/id/57936}
\end{itemize}

\section{Religious and Community Resources}
None identified in the search results.

\section{Digital and Audio Resources}
\begin{itemize}
\item Rosetta Project page for Fore (lists orthography, phonology and text documents; contents not verified): \url{https://rosettapanglossia.longnow.org/index.php?title=For}

\section{Curriculum Development Context}
The scholarly documentation is solid, but no teaching materials were found. A curriculum would have to build on the Scott grammar and dictionary, with Fore community input, and no existing vernacular schooling was identified.
