\section{Introduction}
Wara (ISO 639-3: wbf; Glottocode wara1292) is spoken in southwestern Burkina Faso, in villages near the Mali border in the Cascades region (Leraba province, around Sindou). Joshua Project reports a population of about 11,000. Other names include Ouala, Ouara, Samoe and Samue. Global Recordings Network lists varieties including Soulani, Faniagara, Negueni-Klani and Ouatourou-Niasogoni. The searches found no school materials, so this report is short.

\section{Primary Educational Resources}
