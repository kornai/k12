\section{Introduction}
Tengger (Tenggerese, ISO 639-3 tes) is an Austronesian language, closely related to Javanese, spoken in the Tengger highlands of East Java, Indonesia. A web search found linguistic descriptions and general reference pages. It found no school materials, primers, textbooks or dictionaries in Tengger. Speaker estimates in the sources vary widely and were not verified.

\section{Primary Educational Resources}
No primary educational resources (primers, textbooks, readers) in Tengger turned up in the search.

\section{Linguistic and Reference Materials}
\begin{itemize}
\item Tenggerese dialect, Wikipedia overview: \url{https://en.wikipedia.org/wiki/Tenggerese_dialect}
\item Tenggerese, Wikipedia: \url{https://en.wikipedia.org/wiki/Tenggerese}
\item Thomas Conners, \emph{Tengger Javanese}, Yale PhD dissertation (2008). It covers phonology, morphology, word order and a lexicon chapter, and is the most substantial description found: \url{https://ling.yale.edu/media/417/download}
\item Tengger numerals page, Max Planck Institute for Evolutionary Anthropology: \url{https://lingweb.eva.mpg.de/channumerals/Tengger.htm}
\item Indonesian National Library catalogue record (table of contents) for a study of Tenggerese ritual language: \url{https://ios.perpusnas.go.id/Record/IOS2744.18928/TOC}
\end{itemize}

\section{Curriculum Development Context}
Only linguistic descriptions turned up. A curriculum in Tengger would have to be built from scratch, drawing on the Conners dissertation and on Javanese materials, which were not searched here. Community-based fieldwork is needed.
