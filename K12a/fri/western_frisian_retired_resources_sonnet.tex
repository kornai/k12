\section{Introduction}
The code \texttt{fri} is not a living language but a retired ISO 639-3 identifier. Glottolog lists it as a bookkeeping entry (glottocode west2863) retired with the instruction to change to \texttt{fry}, effective 2007-02-01. Western Frisian itself is now coded \texttt{fry}, and school resources belong in that dossier. Nothing language-specific is catalogued under \texttt{fri}.
\begin{itemize}
\item Glottolog bookkeeping entry: \url{https://glottolog.org/resource/languoid/id/west2863}
\end{itemize}
