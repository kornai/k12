\section{Introduction}
Murui (Murui Witoto, Bue; ISO 639-3 huu) is a Witotoan language of the Colombian and Peruvian Amazon. Search results describe it as little documented before recent fieldwork and spoken by roughly 2,000 people. This report is short because few resources turned up in search; nothing found indicates a school curriculum in Murui.

\section{Primary Educational Resources}
No primers, textbooks or school materials in Murui were found in the search results.

This lists S.\ Burtch (1983), \emph{Diccionario Huitoto Murui} (Yarinacocha: Ministerio de Educaci\'on and Instituto Ling\"u\'istico de Verano), a Murui--Spanish and Spanish--Murui dictionary. No online copy was seen in the search results, so no URL is given for it.
\end{itemize}

\section{Curriculum Development Context}
The Wojtylak grammar is the most complete description found and a sound basis for orthography and grammar content. Burtch's dictionary is a lexical starting point. Any school curriculum would need to be built with Murui communities; no existing programme was found.
