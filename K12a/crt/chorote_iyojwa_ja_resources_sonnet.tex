\section{Introduction}
Iyojwa'ja Chorote (ISO 639-3 crt) is a Mataguayan language of Salta Province, Argentina. Naming across sources is inconsistent with the related Iyo'wujwa variety, so each source's variety must be checked.

\section{Curriculum Development Context}
The language is not known to be taught in schools. A dictionary and a phonological description exist, but no pedagogical grammar or reader was found. Curriculum work needs community partners in Salta.
