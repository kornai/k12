\section{Introduction}
The code \texttt{dkl} (Kolum So Dogon; Glottocode kolu1247) is a retired ISO 639-3 code. According to the IANA registry it was split in 2011 into \texttt{aqd} (Ampari Dogon) and \texttt{dmb} (Mombo Dogon), and the subtag is deprecated. ``Kolum So'' (``sunset dialects'') is a literature label for the westernmost Dogon varieties of Mali. Search snippets give about 19,000 speakers for Mombo and about 5,200 for Ampari (1998). Resources for a curriculum should therefore be sought under Mombo Dogon and Ampari Dogon; no educational materials were found here.

\section{Curriculum Development Context}
Because dkl no longer denotes a single language, a dedicated Kolum So curriculum cannot be planned from this code. Ampari speakers reportedly understand Mombo but not the reverse, which matters when choosing a variety. Further searches should use the codes dmb and aqd.
