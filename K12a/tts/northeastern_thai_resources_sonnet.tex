\section{Introduction}
Northeastern Thai, or Isan (ISO 639-3 tts; Glottocode nort2741), is spoken by roughly 15 million people in Thailand. Thai authorities treat it as a Thai dialect, while many linguists classify it as a Lao variety. It is written today in the Thai script, and the older Tai Noi script is no longer in everyday use. This search found little beyond overviews and scripture listings.

\section{Curriculum Development Context}
Isan is not known to be taught in schools. The Isaan Record notes that there is no written standard, so spelling conventions would need to be agreed before textbooks can be written.
