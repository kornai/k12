\section{Introduction}
Kho'ini (also Xoini, Khoeini, Di; ISO 639-3 xkc; Glottolog khoi1250) is a Tatic Northwestern Iranian language (Indo-European). It is spoken in and around the village of Xoin, roughly 60 km southwest of Zanjan, Iran. Sources describe it as endangered, with Azeri Turkish now dominant locally. The most recent data cited in the sources I found date from the early 1960s. Whether it is a language or a dialect is disputed. I found no school materials in it.

\section{Curriculum Development Context}
Little documentation exists, and the sources suggest the language is disappearing in favour of Turkish. Any curriculum would need fresh fieldwork with remaining speakers, using the Glottolog bibliography to locate early descriptions. This dossier is a starting point, not a resource base.
