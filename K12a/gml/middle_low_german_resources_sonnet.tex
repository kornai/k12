\section{Introduction}
Middle Low German (ISO 639-3 gml; Glottocode midd1318) was the language of the Hanseatic world and has no native speakers. Resources found are scholarly: a historical dictionary and corpus projects. No school materials were found.

\section{Primary Educational Resources}
None found in search results.

\section{Linguistic and Reference Materials}
\begin{itemize}
\item August L\"ubben, \emph{Mittelniederdeutsches Handw\"orterbuch} (full text, Project Gutenberg): \url{https://gutenberg.org/ebooks/61948}
\item Reference Corpus Middle Low German / Low Rhenish (1200--1650), M\"unster project page: \url{https://cris-portal.uni-muenster.de/portal/en/project/9492546}
\item DFG project details for the reference corpus: \url{https://gepris.dfg.de/gepris/projekt/222400659}
\item Glosbe Middle Low German translation pairs (crowd-sourced, not scholarly): \url{https://glosbe.com/gml/mxv}
\end{itemize}

\section{Religious and Community Resources}
None found in search results.

\section{Digital and Audio Resources}
The reference corpus is planned for access through ANNIS; I did not confirm a live interface.

\section{Curriculum Development Context}
Only research-level resources were found. A school unit could use selected edited texts and the Lübben dictionary for reading-based work.
