\section{Introduction}
Valencian Sign Language (Llengua de signes valenciana, LSCV; ISO 639-3: vsv) is used by the deaf community of the Valencian Community in Spain. Several results mix it with Spanish Sign Language (LSE), so each item needs checking for which language it covers. No dedicated LSCV dictionary was found in this search.

\section{Primary Educational Resources}
