\section{Introduction}
Torona (ISO 639-3 tqr; Glottocode toro1251) is a Talodi language of South Kordofan, Sudan. Glottolog lists it as extinct, and Ethnologue labels it dormant. According to Wikipedia, the last speaker died in January 2014, and the community has shifted to Tira. Very little exists beyond a few academic descriptions. No school materials were found.

\section{Curriculum Development Context}
There are no living first-language speakers, so any curriculum would have to be a heritage or documentation project built on Norton and Alaki's description and any recordings or word lists they hold. Tira is the community's current language. This report found no existing educational materials.
