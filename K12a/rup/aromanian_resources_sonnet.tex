\section{Introduction}
Aromanian (ISO 639-3 rup) is an Eastern Romance language spoken in North Macedonia, Albania and Greece. This dossier lists only resources that appeared in web search results. I did not open the pages, so details come from search snippets. No complete K-12 curriculum was found.

\section{Primary Educational Resources}
\begin{itemize}
\item \emph{Tra invitare rum\^aneste: manual de dialect aroman pentru elevii arom\^ani din Albania} (University of Bucharest Press). The search summary credits N. Saramandu, M. Nevaci and I. Floarea, gives 2024 as the year and about 200 pages, and describes teaching units each rendered in standard Romanian. \url{https://editura-unibuc.ro/en/carti-tra-invitare-ramaneste-manual-de-dialect-aroman-pentru-elevii-aromani-din-albania/}
\item PDF of a ``Manual de dialect aroman pentru elevii \c{s}i studen\c{t}ii din Albania'' (lingv.ro, posted October 2025). \url{https://lingv.ro/wp-content/uploads/2025/10/Manual-de-dialect-aroman-pentru-elevii-si-studentii-din-Albania.pdf}
\end{itemize}

\section{Linguistic and Reference Materials}
\begin{itemize}
\item Nisioi (2014), a dictionary of syllabified Aromanian words for computational linguistics. \url{https://aclanthology.org/W14-0616.pdf}
\item Mercator wiki page on Aromanian in the Balkans, which covers the language's status and education. \url{https://wiki.mercator-research.eu/languages:aromanian_in_the_balkans}
\end{itemize}
The search summary also mentioned Papahagi's etymological dictionary, Cunia's 2008 dictionary and Vrabie's 2000 English-Aromanian dictionary. No dictionary URL appeared in the results, so none is cited.
