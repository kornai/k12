\section{Introduction}
Blafe (ISO 639-3: bfh; also Mblafe, Tonda, Indorodoro) is a Papuan language of the Western Province of Papua New Guinea, centred on Indorodoro village in Morehead Rural LLG, with two dialects, Mblafe and R\'anmo. Speaker estimates vary widely between sources (about 350 to 1,200). Very little published material was found in web search; this report lists only what appeared in search results.

\section{Primary Educational Resources}

\section{Curriculum Development Context}
The documentary base for Blafe is thin: only reference-database entries and a catalogue of recordings were found. A native-language curriculum would first require community-led documentation, an agreed orthography, and basic word lists and texts. Any such work should be done with the Blafe community.
