\section{Introduction}
Ubir (also Kubiri, Ubiri) is an Oceanic Austronesian language of the Collingwood Bay coast, Oro Province, Papua New Guinea. Wikipedia places it in the Are--Taupota branch of the Papuan Tip group. Joshua Project's profile gives a different family, Binanderean (Trans-New Guinea). That conflicts with the Austronesian classification and should be treated with caution. Speaker figures vary: about 2,600 (2000 census, per Wikipedia and Omniglot) against about 5,200 on one Bible-society page.
