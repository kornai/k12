\section{Introduction}
The code flm is retired. Falam Chin (also called Lai) is a Kuki-Chin language of Falam Township, Chin State, Myanmar, written in Latin script in Myanmar and, per Asia Harvest, in Bengali script in India. Asia Harvest, citing Joshua Project (2024), gives about 77,000 speakers in Myanmar and 47,000 in India. This report covers what was found in search results only.

\section{Primary Educational Resources}
No primers or school textbooks were found in web searches.

\section{Curriculum Development Context}
The Webonary dictionary and the Bible texts are the main basis for a vocabulary and reading component. No school curriculum in Falam Chin was found. Burmese is the language of state schooling; any mother-tongue programme would need to be developed locally.
