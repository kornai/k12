\section{Introduction}
Northern (Tundra) Yukaghir (ISO 639-3 ykg; Glottocode nort2745) is an endangered language of northeastern Siberia with about 370 speakers, mostly older adults. This report rests on one search round. I found no school materials, only academic works.

\section{Primary Educational Resources}
No primers, textbooks or school programmes were identified in the search results.

\section{Linguistic and Reference Materials}
\begin{itemize}
\item Irina Nikolaeva, \emph{A Historical Dictionary of Yukaghir} (De Gruyter, 2006). It covers all known varieties of Yukaghir in comparative form. Publisher page: \url{https://www.degruyterbrill.com/document/doi/10.1515/9783110892840/html}
\item Catalogue record: \url{https://oeaw.ac.at/resources/Record/9783110892840}
\item Review in LINGUIST List: \url{https://linguistlist.org/issues/17/2562/}
\item SOAS Research Online item, which turned up in the search. I did not open it: \url{https://eprints.soas.ac.uk/4018}
\item Bibliography of Tundra Yukaghir (Surrey Siberian Languages): \url{https://siberianlanguages.surrey.ac.uk/resource/bibliography-tundra-yukaghir/}
\end{itemize}

\section{Religious and Community Resources}
None found.

\section{Digital and Audio Resources}
None found beyond the bibliography above.

\section{Curriculum Development Context}
The search turned up no evidence of school teaching. Documentation is mainly academic, and the speaker population is old, so any curriculum would depend on urgent documentation and community involvement. I found no information on existing programmes.
