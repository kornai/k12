\section{Introduction}
Old Proven\c{c}al (Old Occitan, ISO 639-3 \texttt{pro}) is the medieval ancestor of modern Occitan and the language of the troubadours. It has no native speakers. A curriculum would be a heritage and revitalization one, probably linked to modern Occitan teaching.

\section{Primary Educational Resources}
I found no school materials for Old Occitan. The grammar results from my search covered modern Occitan only.

\section{Linguistic and Reference Materials}
\begin{itemize}
\item \emph{Dictionnaire de l'occitan m\'edi\'eval} (DOM), with a freely accessible online edition. Description: \url{https://tcdh.uni-trier.de/en/newsbeitrag/old-occitan-dictionary-online}
\item DOM dataset record: \url{https://b2find.eudat.eu/dataset/e13f5d75-8f47-5454-a882-2b4ef68e9047}
\item LINDAT repository item related to Old Occitan: \url{https://lindat.mff.cuni.cz/repository/items/31cb7431-188d-46e1-a299-6f12dff9d26c}. I did not check what it contains.
\item Catalogue record for a dictionary of Auvergnat Old Occitan, 1340--1540 (print): \url{https://katalog.lib.cas.cz/KNAV/EdsRecord/nlebk,286215}
\item OeAW catalogue record: \url{https://oeaw.ac.at/resources/Record/9783484971325}. I did not check the title.
\end{itemize}

\section{Religious and Community Resources}
None found in my searches.

\section{Digital and Audio Resources}
The online DOM is the main digital resource found. I found no audio resources.

\section{Curriculum Development Context}
Reference lexicography exists, but I found no free grammar and no pedagogical material. A heritage curriculum would need to be assembled from the dictionary, edited medieval texts, and modern Occitan teaching resources, which I did not search.
