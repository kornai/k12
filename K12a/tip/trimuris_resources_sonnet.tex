\section{Introduction}
Trimuris (ISO 639-3: tip) is a Papuan language of Papua, Indonesia, with roughly 300 speakers cited. It is placed in the Kwerba group, within the Tor--Kwerba / Foja Range grouping. Web searches found very little beyond encyclopedic and mission-listing pages.

\section{Primary Educational Resources}
No primers, textbooks or school materials in Trimuris were found in search results.

\section{Religious and Community Resources}
Joshua Project lists Trimuris as needing translation, with no Bible or audio Bible. Its entry mixes in contradictory details (including an Austronesian description), so it should be treated with caution: \url{https://joshuaproject.net/people_groups/19302}

\section{Digital and Audio Resources}
Global Recordings Network has a listing page for the code tip; the search snippet did not confirm that any audio exists, and the page appears to contain data errors: \url{https://globalrecordings.net/en/language/tip}

\section{Curriculum Development Context}
The language is not known to be taught in schools. No orthography, dictionary or grammar was found. A curriculum would need new fieldwork, documentation and community-led orthography development.
