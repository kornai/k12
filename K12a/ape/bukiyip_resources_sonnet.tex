\section{Introduction}
Bukiyip (also called Mountain Arapesh; ISO 639-3 ape) is a Torricelli (Arapesh) language of East Sepik Province, Papua New Guinea, spoken between Yangoru and Maprik. It has an elaborate noun-class system. It should not be confused with Abelam (Ambulas), a Ndu language.
