\section{Introduction}
East Damar (ISO 639-3 \texttt{dmr}) is an Austronesian language spoken on Damar Island in Maluku, Indonesia. Speaker counts vary by source (about 2,800 in Wikipedia, citing 1990; higher figures elsewhere). It is not closely related to West Damar, the other language of the island. Web searches found very little material suitable for schooling; this report lists only what was found.

\section{Primary Educational Resources}
No primers, textbooks or school programmes for East Damar were found in search results.

\section{Curriculum Development Context}
The language is reportedly used as a first language by the whole community but is not known to be taught in schools. No written teaching materials were located, so any curriculum would need to begin with community-led orthography and materials development, using the sources above only as background.
