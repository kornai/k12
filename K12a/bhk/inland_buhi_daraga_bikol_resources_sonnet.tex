\section{Introduction}
The code bhk (Inland-Buhi-Daraga Bikol, Glottolog alba1269) appears to be a retired ISO 639-3 code that was split into more specific codes; search results list it as deprecated. One successor variety, Buhi'non (ISO 639-3: ubl), is spoken around Buhi, Camarines Sur. No resources specific to ``Inland-Buhi-Daraga Bikol'' as a unit were found. The Buhi'non items below are listed as the closest related materials and should not be assumed to cover other Albay varieties.

\section{Curriculum Development Context}
Albay-area varieties differ from town to town, and Buhi'non is spoken only in a small area around Lake Buhi. Standard Bikol materials from Naga may not suit these speakers well. Before curriculum work, the intended variety and its current ISO code should be settled with local educators.
