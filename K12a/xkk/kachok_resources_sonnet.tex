\section{Introduction}
Kachok (ISO 639-3 xkk; Glottocode kaco1239) is an Austroasiatic language of Ratanakiri province, Cambodia. Web searches found very little. No dictionary, orthography, primer or school material turned up. This report lists only what the searches returned.

\section{Primary Educational Resources}
No primers, textbooks or school programmes for Kachok were found. Joshua Project states that Kachok is not known to be taught in schools:
\url{https://joshuaproject.net/people_groups/18381}

\section{Linguistic and Reference Materials}
\begin{itemize}
\item CUNY doctoral dissertation (2018) describing Kachok sound patterns. It is the first extensive description of the language and is useful as a basis for orthography work: \url{https://academicworks.cuny.edu/gc_etds/2868}
\item Numeral data for Kachok from the Max Planck Institute's Chinese numeral database: \url{https://lingweb.eva.mpg.de/channumerals/Kachok.htm}
\end{itemize}

\section{Religious and Community Resources}
Joshua Project has a people-group profile, which is demographic information only: \url{https://joshuaproject.net/people_groups/18381/CB}. No scripture or community organisation was found.

\section{Digital and Audio Resources}
The Endangered Languages Project has a language page with a sample entry. The search snippet reported no institutional support: \url{https://www.endangeredlanguages.com/lang/1248/samples/11677?hl=de}

\section{Curriculum Development Context}
The language is small. Sources give about 1,000 to 3,000 speakers. It has no known written standard and is not taught in schools. A native-language curriculum would first need community-led orthography and basic materials. The dissertation above is the main linguistic starting point.
