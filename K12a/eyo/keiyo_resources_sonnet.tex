\section{Introduction}
Keiyo (ISO 639-3 \texttt{eyo}) is a Kalenjin variety of the highlands near Eldoret, Kenya. Searches found no Keiyo-specific dictionary, grammar or textbook. Most written resources concern Kalenjin as a whole, so this report is short.

\section{Primary Educational Resources}
None found for Keiyo specifically.

\section{Linguistic and Reference Materials}
None found for Keiyo specifically. Joshua Project's language page gives basic identification data: \url{https://joshuaproject.net/languages/eyo}

\section{Religious and Community Resources}
\begin{itemize}
\item Joshua Project Keiyo people-group page: \url{https://joshuaproject.net/index.php/people_groups/18971/KE}
\item Translator Bible Society news on the new Kalenjin New Testament: \url{https://www.tbsbibles.org/news/694686/Kalenjin-New-Testament-Published.htm}
\item Kalenjin translation project: \url{https://www.tbsbibles.org/news/662491/The-Kalenjin-Translation-Project.htm}
\item Kalenjin Old Testament files received: \url{https://www.tbsbibles.org/news/727603/Kalenjin-Old-Testament-Files-Received.htm}
\end{itemize}
The Kalenjin translation is not a Keiyo-specific Bible; Joshua Project lists a Keiyo translation as started.

\section{Digital and Audio Resources}
Global Recordings Network lists audio-visual Bible lessons in Keiyo (Geyo): \url{https://globalrecordings.net/en/language/3019}

\section{Curriculum Development Context}
Keiyo is not known to be taught in schools. A curriculum would likely draw on Kalenjin materials and require new Keiyo-specific primers and orthography work.
