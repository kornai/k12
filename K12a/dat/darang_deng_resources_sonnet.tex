\section{Introduction}
Darang Deng (ISO 639-3 \texttt{dat}) is an alternate name for Digaro-Mishmi (Taraon), ISO 639-3 \texttt{mhu}; Glottolog notes that the older code \texttt{dat} was merged into \texttt{mhu} in 2008. It is spoken mainly in Arunachal Pradesh, India, with some speakers in Zayu County, China. Speaker estimates range widely, from about 6,000 to about 45,000. The ``Bookkeeping'' family label supplied with the request is a Glottolog placeholder.
