\section{Introduction}
Foau (ISO 639-3 flh) is a Lakes Plain language of Papua, Indonesia. The search results indicate it is now usually called Abawiri. Only academic description was found. No school materials, primers or community resources appeared.

\section{Curriculum Development Context}
The language is described as having seven vowels, complex tone and no nasal consonants. Before Yoder's work it was known mostly from short wordlists. Any curriculum would need an orthography and materials built with the community.
