\section{Introduction}
Ami (ISO 639-3 amy; Glottocode amii1238) is a Western Daly language of the Northern Territory, Australia, with very few speakers. My searches turned up almost nothing specific to this language. Search results mixed it with neighbouring Daly-region languages (Emmi, Marri Ngarr, Mati Ke), and I could not confirm from them which materials concern Ami itself, so I cite none of those. An honest summary is that I found only catalogue-level entries.
