\section{Introduction}
Firan (F\'iran, fir) is a Niger-Congo language spoken in villages of Ganawuri District, Riyom LGA, Plateau State, Nigeria. It should not be confused with Fyer, a Chadic language of the same state. It is very small (about 2,500 to 5,000 speakers by different estimates) and is not known to be taught in schools. Only one general reference page was found.
