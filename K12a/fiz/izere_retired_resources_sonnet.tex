\section{Introduction}
The code fiz is a retired ISO 639-3 identifier, not a living language in its own right. Per Glottolog, change request 2007-147 split it into Ganang [gne] and Izere [izr], effective 14 January 2008. The family label ``Bookkeeping'' in the identification is a Glottolog bookkeeping category, not a linguistic family. Resources should be sought under izr (Izere, Nigeria; Glottolog lists it as threatened) and gne.
