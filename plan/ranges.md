# Alphabet split between the box and the cloud sessions

The author's machine runs the Claude pass alphabetically and stops at `szz`
(driver option `--end szz`). Cloud sessions take `t` to `z`, 1,737 languages,
one session per range, started with "Run the survey loop on range <lo-hi>":

| range | codes | status |
|---|---|---|
| t-tzz | 545 | |
| u-wzz | 461 | |
| x-xzz | 297 | |
| y-zzz | 434 | |

A session that finishes its range reports "NOTHING PENDING" and can be given
another. Ranges are inclusive, compared as strings.
